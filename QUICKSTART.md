# Quick Start - 3 Steps

## Step 1: Install Node.js
Download and install from **[nodejs.org](https://nodejs.org)** (v14+)

## Step 2: Run These Commands
```bash
git clone https://github.com/scentcafe28-creator/ScentCafe.git
cd ScentCafe
npm install
npm start
```

## Step 3: Open in Chrome
Go to: **http://localhost:3000**
