# ScentCafe PWA

This package turns the ScentCafe prototype into a Progressive Web App.

## Included
- ScentCafe app icon
- Android Add to Home Screen support
- Standalone app display
- Service worker/offline app shell
- Existing Home, Services and Account prototype screens
- PWA manifest and icons

## Important
A PWA must be served from HTTPS (or localhost during development) for the service worker and installation features to work.
