# ScentCafe PWA

This package turns the ScentCafe prototype into a Progressive Web App.

## Included
- ScentCafe app icon
- Android Add to Home Screen support
- Standalone app display
- Service worker/offline app shell
- Existing Home, Services, AI, WiFi and Account prototype screens
- PWA manifest and icons

## Important
A PWA must be served from HTTPS (or localhost during development) for the service worker and installation features to work.

## Android
1. Upload/host this folder on an HTTPS website.
2. Open the website in Chrome on Android.
3. Use Chrome's Install app / Add to Home screen option.
4. ScentCafe will open as a standalone app with its own icon.

The AI, WiFi payments, customer accounts and service requests are still prototype interfaces and need their respective backend/API connections before they can process real transactions.
